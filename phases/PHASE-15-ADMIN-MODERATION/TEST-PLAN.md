# Phase 15 Test Plan

- Parameterized role/capability tests across every privileged endpoint.
- Self-escalation, other-user role change, last-admin/self-demotion and suspended account cases.
- Report create/view/assign/resolve and reporter-privacy tests.
- Content hide/remove/restore and linked feed/search/Library visibility.
- Reputation award reversal/restoration after moderation.
- Payment/AI admin projections sanitized.
- Audit records contain actor/action/target/reason/correlation but no secrets.
- E2E moderator queue/action vs admin-only role/payment actions.
- Responsive/a11y for dense tables, filters, dialogs and mobile detail workflow.
