# Stitch MCP — Phase 11 Membership & Payments

## Prompt A — Pricing / Membership Body
```text
Design membership pricing for CongDongNgonNgu.vn with a community-first, transparent tone. Plans: FREE and COMMUNITY MEMBER. Free must look genuinely useful, not a crippled bait tier. Member benefits may include larger AI quota, advanced practice/analytics, enhanced matching, private rooms and premium events/resources only when implemented. Also provide a clear contribution-earned membership/credit path when available.

Avoid fake discounts, countdown timers, preselected expensive choices, visually shaming Free users, hidden renewal terms or excessive “premium gold” styling. Show price/period, actual entitlements, current plan and upgrade path. Mobile comparison must remain readable without a huge horizontal table.
```

## Prompt B — Checkout & Payment States
```text
Design PayOS checkout/payment body using trusted CongDongNgonNgu shell. Show server-defined plan, amount, order summary, payment instructions/QR if provider supplies it, pending/paid/failed/cancelled/retry states and clear navigation after result. Do not imply payment completed until server-confirmed fulfillment. Keep QR/code panels within mobile viewport. Error copy must not expose provider signatures/internal IDs.
```

## Prompt C — Membership Account
```text
Design account membership status/history: current entitlement/expiry, contribution credit if applicable, payment history safe summary, renewal/cancel semantics only if actually supported, and help/reconciliation state. No dark patterns around cancellation or failure recovery.
```
