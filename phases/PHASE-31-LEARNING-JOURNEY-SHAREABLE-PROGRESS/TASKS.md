Audit every existing XP/reputation/activity source and freeze truthful server-backed definitions.

## LNG-31-002 — Journey dashboard Stitch/redesign
Design strong stat hierarchy, streak/time/session cards, progress visualization, achievements and milestones for desktop/mobile.

Implement only missing metrics that can be derived accurately from durable events/data; define timezone/reset/idempotency rules.

Improve iconography, unlocked/locked states, progress-to-next and recent achievement emphasis.

## LNG-31-005 — Shareable progress cards
Create privacy-aware share cards for selected real metrics/achievements with preview and explicit user action.

## LNG-31-006 — Acceptance
Validate correctness, privacy, time-boundary behavior, seven widths, accessibility and lifecycle closure.
