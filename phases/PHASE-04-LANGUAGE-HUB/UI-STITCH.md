## Prompt A — Language Explorer Body
```text
Design a Language Explorer body for CongDongNgonNgu.vn using existing global shell/tokens. Initial catalog: Vietnamese, English, Chinese, Japanese, Korean, French, German, Spanish, but design must clearly scale to more languages. Provide search/discovery, language identity and concise community/learning context only from real data. Avoid a grid of giant identical course cards; this is a community knowledge portal, not an LMS catalog.

Desktop should scan quickly with useful grouping/list/grid hybrid; mobile must support thumb-friendly search and compact language rows/tiles. Flags may be optional decoration, never the only identifier.
```

## Prompt B — Reusable Language Hub Header + Body
```text
Design the reusable hub for one language (example English) without creating a language-specific visual template. Required sections: Overview, Vocabulary, Grammar, Sentences, Pronunciation, Resources, Community, Questions, Practice, Exchange. Include language identity, optional A1–C2 level filter, topic/filter controls, featured/active content and truthful empty/coming-soon states for modules not yet implemented.

The hub must feel alive and community-centered, but never fabricate online counts. Desktop 1024/1440: clear content hierarchy with optional contextual rail. Tablet/mobile: section navigation must remain usable (scrollable tabs, menu or segmented pattern) without horizontal overflow. Avoid ten cards representing ten tabs. Return header/navigation/body/loading/empty states.
```
