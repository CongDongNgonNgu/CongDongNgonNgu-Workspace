# Phase 30 Tasks

## LNG-30-001 — Architecture & threat model
Freeze attachment entity/storage/access/lifecycle contracts, allowed types/limits, privacy model and abuse controls.

## LNG-30-002 — Shared backend/storage foundation
Implement shared upload/finalize/read/delete authorization, validation, metadata, storage abstraction, safe URLs and cleanup.

## LNG-30-003 — Shared frontend composer/preview
Create reusable attachment picker, preview, progress, retry/remove/reorder patterns and accessible states.

## LNG-30-004 — Community integration
Enable approved media/file attachments in supported Community post flows without weakening post semantics.

## LNG-30-005 — Group/message integration
Enable approved attachments in private groups/messages with fresh authorization checks on access.

## LNG-30-006 — Security/performance/runtime acceptance
Adversarial file validation, private-access checks, rate/size bounds, orphan cleanup, responsive/a11y, exact-owned fixture cleanup and lifecycle closure.
