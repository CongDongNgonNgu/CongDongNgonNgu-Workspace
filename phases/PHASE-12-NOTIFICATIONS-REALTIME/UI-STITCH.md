# Stitch MCP — Phase 12 Notifications

## Prompt A — Desktop Notification Dropdown/Panel
```text
Design a compact desktop notification experience for CongDongNgonNgu.vn header. It must open/close reliably by trigger, outside click and Escape; support focus management, unread badge, read/unread styling, safe actor/target projection and a link to full notification center. Notification families include replies, corrections, accepted answers, buddy requests, room invites, badges, membership and moderation/system events.

Avoid a huge social-media clone or overly colorful icons. Long multilingual text should wrap. Deleted/system actors must have graceful neutral representation. The panel must never overflow viewport.
```

## Prompt B — Mobile Notification Center
```text
Design a dedicated mobile-first notification screen rather than a tiny dropdown. Include unread/all or useful category filters, mark-read affordance, preferences entry and readable grouped chronology. Target 320–412 with bottom navigation/safe area. Use clear tap targets and no accidental swipe-only actions. Show empty/offline/reconnecting states.
```
