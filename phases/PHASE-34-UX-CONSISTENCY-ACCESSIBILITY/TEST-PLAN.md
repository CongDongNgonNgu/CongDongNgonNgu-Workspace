# Phase 34 Test Plan

Build a route/state matrix for critical surfaces and run VI/EN at seven widths. Verify navigation/active states, direct URL/back-forward/refresh, header/footer, forms/cards/actions, long localized copy, empty/loading/error/success states, keyboard tab order, visible focus, semantic names, accordion expanded state, contrast checks and horizontal overflow.

Record automated accessibility tooling separately from any manual screen-reader coverage; do not claim formal WCAG certification.
