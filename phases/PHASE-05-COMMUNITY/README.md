# Phase 05 — Community Core

## Goal
Build a learning-oriented community layer, not a generic social network. Posts and interactions must carry language-learning context and become foundations for Corrections, Open Library, Reputation and Notifications.

## Post types
`DISCUSSION`, `QUESTION`, `RESOURCE`, `LEARNING_JOURNAL`, `CULTURE`, `PRONUNCIATION_REQUEST`, `CORRECTION_REQUEST`, `CHALLENGE`.

## Core principles
Feed relevance favors the user’s learning languages, usefulness and recency without addictive engagement optimization. Report/save/share/privacy behaviors are explicit. Community content must be moderation-ready from the first release.

## Completion gate
Post/comment/reply/reaction/tag/feed/report/save flows work with authorization and abuse controls; Stitch-designed composer/feed/post detail are responsive/accessibility-checked; tests/commits/CI pass.
