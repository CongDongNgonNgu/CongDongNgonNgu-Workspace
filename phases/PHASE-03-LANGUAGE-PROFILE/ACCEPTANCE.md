# Phase 03 Acceptance

- Eight launch languages are available through an extensible data-driven catalog; adding a ninth does not require schema duplication.
- Users can represent multiple native/known/learning languages and valid proficiency values.
- Goals/skills/interests/timezone/availability are structured enough for later matching without unnecessary public exposure.
- Onboarding can be completed on mobile/desktop, survives normal navigation/refresh, and does not force optional data.
- Language Passport has distinct own/public projections and honors privacy.
- Backend rejects unauthorized profile edits and invalid language relationships.
- No fake reputation/achievement values are displayed before Phase 10.
- Stitch workflow, responsive/a11y evidence, tests, commits and CI are complete.
