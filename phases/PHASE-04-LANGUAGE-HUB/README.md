# Phase 04 — Language Hub

## Goal
Create a reusable hub architecture so each language feels like an active learning/community destination without duplicating page code eight times.

## Hub sections
Overview, Vocabulary, Grammar, Sentences, Pronunciation, Resources, Community, Questions, Practice and Exchange. Sections may initially show verified empty/coming-soon states when their later phase is not implemented; they must not link to broken routes.

## Routes
Use stable language slugs/IDs and canonical routing such as `/languages/:slug`. Public hub content should be SEO-ready even if full SEO hardening comes in Phase 16.

## Completion gate
Reusable language hub shell, catalog/discovery and section navigation implemented; data contract works for all eight launch languages; responsive Stitch design complete; no duplicated per-language page implementations; tests/commits/CI pass.
