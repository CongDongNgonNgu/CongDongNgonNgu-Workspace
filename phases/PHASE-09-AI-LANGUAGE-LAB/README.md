# Phase 09 — AI Language Lab

## Goal
Deliver purposeful AI-assisted language practice tied to learner level and trusted community/library context. This is not a generic chatbot and must not clone Talkpal UI or mode structure.

## Initial modes
AI Conversation, Writing Coach, Grammar Coach, Roleplay and “Learn from Community/Library”. Roleplay scenarios include airport, restaurant, hotel, job interview, shopping, travel, business meeting and doctor.

## Principles
Provider-independent architecture, cost/rate limits, safe logging, explicit model/feature availability, provenance-aware retrieval and clear distinction between generated suggestions and verified language knowledge.

## Completion gate
Provider abstraction, quota/cost controls and approved modes work with resilient UX; Library/community context respects permissions/provenance; Stitch design passes responsive/a11y; safety/cost/tests/commits/CI evidence complete.
