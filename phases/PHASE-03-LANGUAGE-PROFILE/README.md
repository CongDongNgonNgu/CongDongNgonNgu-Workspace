# Phase 03 — Language Profile & Onboarding

## Goal
Transform generic user identity into a useful multilingual learning identity that powers Language Hubs, Exchange, personalization and community context.

## Domain
`Language`, `UserLanguage`, `LanguageLevel`, `LearningGoal`, `UserInterest`, `Timezone`, `Availability` plus profile/privacy metadata as justified.

Initial languages: Vietnamese, English, Chinese, Japanese, Korean, French, German and Spanish. The data model must allow adding languages without schema changes.

Proficiency baseline: A1, A2, B1, B2, C1, C2 and Native; do not force CEFR onto contexts where a language/profile requires a different future framework—keep the model evolvable.

## Completion gate
Extensible catalog, onboarding, profile edit and Language Passport are implemented/tested; privacy and validation boundaries work; Stitch-designed flows are responsive/accessibility-checked; commits pushed and CI green.
