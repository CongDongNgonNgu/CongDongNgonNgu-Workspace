# Stitch MCP — Phase 05 Community

## Prompt A — Feed Body
```text
Design the learning-oriented Community Feed body for CongDongNgonNgu.vn. This is not Facebook/Twitter. Posts carry language-learning intent and types: Discussion, Question, Resource, Learning Journal, Culture, Pronunciation Request, Correction Request, Challenge. Show target language, optional CEFR/topic and author language context without visual overload.

Desktop may use a primary feed plus lightweight contextual filters/rail; mobile must prioritize readable posts, composer access and filters rather than stacking sidebars. Feed actions: comment, helpful/reaction, save, share, report. Avoid engagement-bait counters and oversized reaction bars. Include loading, empty, moderated/deleted and error states.
```

## Prompt B — Post Composer
```text
Design a post composer for language learning community. User chooses post type, target language, optional level/topic and writes content; specialized types can reveal contextual fields progressively. Avoid a huge all-fields form. Provide autosave/retry or draft visual state only if implementation supports it. Mobile keyboard must not obscure Publish/Cancel; errors and remaining limits are accessible.
```

## Prompt C — Post Detail & Comments
```text
Design a detailed post page with readable content, language metadata, author identity, safe actions and threaded comments/replies. Thread depth should remain understandable on narrow screens; avoid endless indentation. Provide deleted/moderated reply state and report menu. Include keyboard/focus states and long Vietnamese/CJK content examples.
```
