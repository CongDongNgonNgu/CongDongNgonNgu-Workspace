# Phase 33 Tasks

## LNG-33-001 — Framework/content audit
Inventory supported languages, current proficiency data, recognized frameworks, trustworthy mapping sources and resource availability. Freeze evidence rules.

## LNG-33-002 — Language Hub Stitch/redesign
Create richer language overview/resource category/level-explanation layouts and mobile targets.

## LNG-33-003 — Proficiency framework registry
Implement a data model allowing language-specific framework, ordered levels, labels, descriptions and optional evidence-backed cross-framework references.

## LNG-33-004 — Rich resource journeys
Add previews and meaningful next actions for vocabulary/sentences/resources, plus saved/recent/recommended entry points only where supported truthfully.

## LNG-33-005 — Unavailable/empty learning states
Make grammar/pronunciation/practice blockers understandable, with measurable re-entry conditions instead of dead text cards.

## LNG-33-006 — Acceptance
Validate languages/frameworks, provenance/licensing, VI/EN, seven widths, accessibility, direct navigation and lifecycle closure.
