# Phase 17 — Security & Privacy Hardening

## Goal
Perform a cross-domain threat-model and adversarial hardening pass before production UAT. This phase verifies and strengthens security already implemented earlier; it is not permission to postpone basics.

## Scope
Auth/OAuth/session, authorization/IDOR, web security, uploads, rate limits/abuse, community privacy, exchange/contact safety, Library provenance/review, AI prompt/data boundaries, payments/webhooks, realtime/rooms/events, admin/audit, secrets/logging, privacy/retention and dependency/config posture.

## Completion gate
Threat model documented; critical/high findings fixed or formally blocked with owner; negative tests and dependency/config scans pass to approved threshold; privacy/retention decisions are explicit; commits/CI/evidence complete.
