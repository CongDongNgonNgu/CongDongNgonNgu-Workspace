# Product Vision

**CongDongNgonNgu.vn — Global Language Community** is a cross-border language learning and sharing platform combining people, open knowledge and AI-assisted practice.

Core loop: `learn → ask/share → human correction/contribution → verification → reusable Open Language Library → AI-assisted practice → more capable contributors`.

Primary audiences: Vietnamese learners of foreign languages; foreigners learning Vietnamese (“Vietnamese for the World”); native/advanced contributors; language experts/moderators/hosts.

Initial languages: Vietnamese, English, Chinese, Japanese, Korean, French, German and Spanish. This is launch scope, not a schema limit.

Product pillars: Language Identity, Language Hubs, Community Learning, Language Exchange, Open Language Library, AI Language Lab, Contribution Economy and sustainable Membership.

Success should measure healthy learning/community outcomes such as useful corrections, verified contributions, completed exchange sessions, active contributors, moderation quality, learning retention and AI cost per useful session—not raw addictive engagement.

MVP non-goals include teacher marketplace, native mobile app, 100+ languages, advanced speech scoring, large-scale ML recommendation, organization spaces and certificates.
