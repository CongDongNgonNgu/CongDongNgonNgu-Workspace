# Stitch MCP — Phase 08 Open Language Library

## Prompt A — Knowledge Explorer
```text
Design the Open Language Library body for CongDongNgonNgu.vn as a trustworthy knowledge explorer, not an LMS course catalog. Resource types: vocabulary, sentences, translations, grammar, dialogues, idioms, slang, cultural notes, pronunciation, collections. Required filters: language, type, keyword, topic, level where relevant. Show source/review/attribution cues without overwhelming users.

Desktop may use a compact filter rail plus results; mobile needs a filter drawer/sheet and readable mixed-type result rows. Avoid giant identical cards. Verified status must be distinct from community-review/draft states where the current user is authorized to see them. Public users should not see internal rejection notes.
```

## Prompt B — Resource Detail & Contribution
```text
Design resource detail showing learning content first, then translation/examples/context, source attribution/license and review confidence/state. For community contribution, create a progressive form that explains reuse/licensing expectation before submit, supports language/type-specific fields and clearly says submission enters review rather than instant verification. Include contributor identity only according to privacy settings.
```

## Prompt C — Reviewer Queue
```text
Design a focused review experience for authorized contributors/moderators: compare submitted content, provenance/source, duplicate warnings, review notes and Approve/Reject/Request changes if implemented. Avoid admin-dashboard overload; make evidence and language content central. Mobile should support review detail even if bulk operations remain desktop-oriented.
```
