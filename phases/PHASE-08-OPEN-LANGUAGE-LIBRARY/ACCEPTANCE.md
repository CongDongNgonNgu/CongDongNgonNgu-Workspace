# Phase 08 Acceptance

- Every durable resource exposed publicly has provenance/review state and applicable license/attribution metadata.
- Community submissions do not become verified automatically.
- Search/filter works across language/type/topic/level without exposing rejected/private review data.
- Verification is authorization-controlled and audit/reversal capable.
- Correction/Q&A candidates preserve source provenance.
- Tatoeba adapter runs only after authoritative current license/attribution validation; blocked state is acceptable if external terms prevent safe ingestion, but core Library phase must still be functional with community/seed data.
- Import is idempotent and does not discard attribution during dedup.
- Stitch/responsive/a11y, tests, commits and CI evidence complete.
