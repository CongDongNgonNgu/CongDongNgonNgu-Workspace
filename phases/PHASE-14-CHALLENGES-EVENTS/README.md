# Phase 14 — Challenges & Events

## Goal
Create healthy shared learning rhythms through finite challenges and community events without manipulative streak pressure.

## Examples
Challenges: 7-day speaking, 30-sentence practice, Vietnamese Week, pronunciation challenge. Events: English Coffee Talk, Vietnamese for Foreigners, beginner Japanese room.

## Core behavior
Challenge definition/eligibility/progress/completion; event scheduling/registration/capacity/reminders/attendance/host/recurrence. Integrate Speaking Rooms when event type uses a room.

## Completion gate
Configurable challenges/events, registration/attendance/reminders and Stitch-designed discovery/detail flows work across timezone/mobile cases; tests/commits/CI complete.
