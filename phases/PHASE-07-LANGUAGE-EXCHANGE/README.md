# Phase 07 — Language Exchange

## Goal
Make safe human-to-human cross-border practice a core differentiator through Language Buddy discovery and matching based on reciprocal language value, level, timezone, availability, interests and goals.

## Safety principle
Discovery does not reveal private contact details. Connection, messaging/contact permissions, block/report and visibility controls are explicit. Compatibility is assistance, not a guarantee of trust.

## Matching V1 signals
- Native/known ↔ learning language complementarity.
- Level compatibility.
- Timezone and opt-in availability overlap.
- Shared interests and learning goals.
- Safety/visibility eligibility.

## Completion gate
Preferences, deterministic matching/discovery, connection requests, partner profile preview and safety/privacy controls work; UI follows Stitch; tests include privacy/abuse; commits/CI/evidence complete.
