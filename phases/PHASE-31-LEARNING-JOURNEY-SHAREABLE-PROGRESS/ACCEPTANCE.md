# Phase 31 Acceptance

- Every displayed metric has a documented durable source and definition.
- Learning XP and Community Reputation are visually/semantically distinct.
- Streak/time/session/achievement values survive refresh and use defined timezone/reset rules.
- Missing data is represented honestly rather than as fake zero/competition data when zero is not meaningful.
- Ranking/percentile appears only if a trustworthy contract exists.
- Progress dashboard is visually scannable and motivating on desktop/mobile.
- Share cards expose only user-approved, privacy-safe data.
- Full automated/runtime/responsive/a11y/review/lifecycle gates pass.
