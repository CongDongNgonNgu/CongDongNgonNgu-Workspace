# Stitch MCP — Phase 09 AI Language Lab

## Prompt A — AI Lab Home/Mode Selection
```text
Design the AI Language Lab body for CongDongNgonNgu.vn. It must feel integrated with a human community, not like a cloned standalone AI tutor. Available modes: Conversation, Writing Coach, Grammar Coach, Roleplay, Learn from Community/Library. Show target language/level context and current quota/availability calmly. Avoid a wall of glowing gradient AI cards.
```

## Prompt B — Conversation & Roleplay Workspace
```text
Design an AI conversation/roleplay workspace with readable dialogue, learner/AI distinction, scenario goal, target language/level, optional explanation action, stop/retry and session-end feedback. Streaming/error/quota/provider-offline states must be first-class. Mobile 320–412 must handle virtual keyboard, long messages and fixed composer without hiding content. Roleplay scenarios are configurable; do not design separate visual apps for airport/restaurant/etc.
```

## Prompt C — Writing/Grammar Coach
```text
Design Writing Coach and Grammar Coach bodies using the project's accessible correction diff. User input remains visible; output is structured into corrected text, explanation, natural alternative and focused practice. Clearly label AI-generated guidance and never imply native/expert verification. On mobile use stacked sections; on desktop avoid overly wide text lines.
```

## Prompt D — Learn from Community
```text
Design the action/result for “Học từ bài này / Learn from this” on a community or Library resource. Preserve source link/attribution and generate vocabulary, grammar notes, mini quiz and speaking prompts. Make source provenance visible; distinguish generated study material from verified source content.
```
