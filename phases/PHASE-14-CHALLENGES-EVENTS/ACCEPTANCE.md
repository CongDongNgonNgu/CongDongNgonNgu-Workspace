# Phase 14 Acceptance

- Challenges are data/config-driven and progress uses trusted domain events.
- Challenge UX communicates finite goals without shame/dark urgency.
- Event timestamps/recurrence are timezone-safe and display correctly for participants.
- Registration is idempotent and capacity-safe under concurrency.
- Reminders respect preferences/timezone; cancellation updates pending notifications where feasible.
- Attendance has explicit evidence and does not award value from page views alone.
- Speaking-room events retain Phase 13 room authorization.
- Stitch/responsive/a11y, timezone/concurrency/safety tests, commits and CI evidence complete.
