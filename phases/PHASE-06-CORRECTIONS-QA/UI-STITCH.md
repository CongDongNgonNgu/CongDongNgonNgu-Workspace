## Prompt — Correction Request, Editor & Diff
```text
Design the correction/Q&A body for CongDongNgonNgu.vn using existing community shell. Core flow: learner submits original text/question with target language/level/context; another user proposes a correction and explanation; requester/community can mark helpful/accepted according to rules.

The correction diff must remain understandable without red/green color alone. Show Original → Corrected with insertion/deletion/changed spans, explanation and author/reviewer identity. Long paragraphs and Vietnamese/CJK content must remain readable. On mobile avoid side-by-side columns that force tiny text; use stacked synchronized blocks or an accessible inline diff. Clearly distinguish “Accepted by asker” from “Verified resource”.

Provide correction editor, vote/helpful, accept, report and Library-candidate states. Do not gamify correctness. Include loading, deleted/moderated response and no-correction-yet states.
```

Refine if diff uses color only, mobile text becomes cramped, or acceptance looks like formal linguistic verification.
