# Phase 01 Acceptance

Accept only when:
- Semantic tokens and usage rules are documented and implemented.
- Header, footer, mobile navigation and global shell were designed through Stitch MCP and the accepted design intent is recorded.
- No active nav links point to unimplemented/dead destinations without an intentional feature gate.
- Core primitives expose hover/focus/disabled/loading/error states where applicable.
- Major shell surfaces work at 320, 375, 390, 412, 768, 1024 and 1440 without horizontal overflow or clipped controls.
- Keyboard navigation, focus visibility and landmark semantics pass review.
- Visual comparison confirms the product does not look like EduAI/Talkpal or a generic dashboard.
- Visual/component tests and build pass; commits pushed and CI checked.
