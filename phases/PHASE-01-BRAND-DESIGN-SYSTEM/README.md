# Phase 01 — Brand, Design System & Global Shell

## Goal
Create the independent visual language and global application shell for CongDongNgonNgu before feature pages multiply. The result must clearly differ from EduAI and avoid imitating Talkpal or generic AI dashboards.

## Core surfaces
- Brand token foundation from current logo concept: navy, orange, green, cyan.
- Typography, spacing, radius, shadows, elevation, grid and motion.
- Desktop Header and navigation.
- Mobile Header and bottom navigation.
- Footer.
- Core reusable UI primitives and responsive shell.

## Required design workflow
Every user-facing design task in this phase must use Stitch through MCP according to `UI-STITCH.md` and `AGENTS.md` before implementation.

## Completion gate
Approved Stitch references recorded; tokens/components implemented; global shell responsive and accessible at required viewports; visual regressions added; implementation committed/pushed; no substantial visual resemblance to EduAI.
