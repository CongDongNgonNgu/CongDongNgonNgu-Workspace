Add source-grounded related-resource exploration to the public Library through the relational approach validated by Phase 21.

## Scope after entry gates pass
Bounded public relation projection; paginated related-resource source cards/navigation; language/type/level eligibility; provenance/license display; current access/source-health rechecks; invalidation of stale/deleted relations; lexical fallback/abstention; vi/en localization only for the new UI.

Phase 21 `GO`, reviewed relation ownership/update process, bounded TEST contracts and separate Phase 23 owner authorization.
