# Phase 09 Acceptance

- Frontend never receives provider secrets; disabled/misconfigured providers fail safely.
- Usage/quota/cost accounting is measurable and retry behavior avoids obvious double charging where controllable.
- AI modes adapt to learner context but do not treat user/retrieved text as privileged hidden instruction.
- Writing output has structured correction/explanation/natural alternative; Grammar Coach includes focused practice.
- Roleplay is scenario-configurable rather than duplicated pages.
- Learn-from-content uses only authorized, provenance-aware sources and does not expose rejected/private content.
- Generated output is not mislabeled as verified community knowledge.
- Provider outage/quota/error states have usable UI; Stitch/responsive/a11y, tests, security/cost, commits and CI evidence complete.
