# Stitch MCP — Phase 07 Language Exchange

## Prompt A — Partner Discovery
```text
Design Language Buddy discovery for CongDongNgonNgu.vn. Emphasize reciprocal learning value and humanity, not dating/swipe mechanics. Each match should explain why: their native/known language helps the learner, learner can help them, compatible level/timezone/availability/interests/goals. Never expose exact private schedules, email or phone.

Desktop can use filters plus a clean list/grid of partner summaries; mobile should use vertically readable profiles with compact filters. Actions: View profile, Send request, Block/Report in secondary menu. Show match reasons as concise accessible text, not opaque percentages alone. Include no-match state with suggestions to broaden safe preferences.
```

## Prompt B — Buddy Profile Preview & Preferences
```text
Design public buddy profile preview based on Language Passport: languages/levels, learning goals, selected interests, safe availability summary and real reputation if available. Include connection state/request actions and prominent-but-not-alarming safety controls. Also design preferences screen for opt-in, languages offered/wanted, timezone/availability visibility and discovery controls. Mobile privacy controls must be easy to understand and not buried.
```
