# Stitch MCP — Phase 13 Speaking Rooms

## Prompt A — Room Discovery/Detail
```text
Design speaking-room discovery for CongDongNgonNgu.vn: language, level, topic, host, public/private, scheduled/live state and real participant counts. Avoid visual similarity to video meeting software or social audio clones. Emphasize language-practice purpose. Mobile list/filter should be compact and readable; do not fabricate “live now” activity.
```

## Prompt B — Live Audio Room
```text
Design a mobile-first live audio language room body. Required hierarchy: topic/language/level, speakers, listeners, host/moderator cues, raise hand and speaker queue, microphone state, room chat access, leave, report/moderation actions. Provide microphone permission denied, reconnecting, provider outage, full/private room and removed-by-moderator states.

No video-grid aesthetic. Controls must remain reachable with safe areas and not obscure chat/content. Clearly communicate when microphone is live. Recording must NOT appear enabled by default; any consented transcription/AI summary path requires explicit separate consent UI.
```

## Prompt C — Consent for AI Feedback
```text
Design an explicit optional consent step for transcription/AI post-room feedback. Explain what audio/transcript is processed, what is stored/retained according to implemented policy and how to decline while still using the normal room. No prechecked consent and no vague “improve experience” copy.
```
