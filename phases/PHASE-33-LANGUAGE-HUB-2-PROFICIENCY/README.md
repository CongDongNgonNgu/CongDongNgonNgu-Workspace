# Phase 33 — Language Hub 2.0 & Proficiency Frameworks

**Status:** PLANNED — NOT STARTED

## Objective
Transform each language page from a mostly textual directory/filter launcher into a living learning hub with richer resource journeys and truthful, understandable proficiency frameworks.

## Proficiency principle
CEFR is not English-only, but it must not be forced as the only visible native framework for every language. Support a language-prevalent/native framework and an optional comparable/reference framework only where a trustworthy mapping exists.

Examples to investigate, not blindly hard-code: CEFR where appropriate, JLPT for Japanese, HSK for Chinese, TOPIK for Korean and other recognized frameworks. Never fabricate crosswalk equivalence.

Each visible level needs plain-language explanation of what the learner can generally understand/do.

## Resource direction
Vocabulary, sentence and resource cards should offer meaningful previews/next actions rather than merely redirecting to a generic pre-filtered Library. Grammar/pronunciation/practice unavailable states must be useful and evidence-backed.
