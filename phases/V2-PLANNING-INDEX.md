## How to use these dossiers

Each executable dossier contains the standard operational files expected by the Codex
startup contract: `README.md`, `TASKS.md`, `ACCEPTANCE.md`, and `TEST-PLAN.md`.
User-facing phases also carry `UI-STITCH.md` where UI policy needs to be explicit.
Phase-specific planning artifacts capture authorization matrices, threat models,
benchmarks, policy contracts, relation contracts or copy inventories.

Planning records alone prove no code, fixture, deployment or real-user result. The
authoritative product ordering and cross-phase dependency semantics remain
`docs/V2-ROADMAP.md`; the detailed Language Hub addition is in
`docs/V2-ROADMAP-PHASE-23-LANGUAGE-HUB-AMENDMENT.md`.
