## Findings and dispositions

1. **Acceptance concurrency gap (required later002):** service prechecks current eligibility; SQL locks only parent/response identity, so hidden/disabled changes can race acceptance. Unique acceptance cardinality is proven by schema, current eligibility under race is not. Freeze stronger affected-path gate; do not claim atomic safety today. No broad001 fix.
2. **Search eligibility/cursor gap (required003):** existing SQL omits email verification before pagination; service suppresses later and cursor can reveal last scanned timestamp/ID. New search must move complete eligibility to DB and use scoped encrypted continuation; prove no hidden count/scan identity. Existing v1 unsigned cursor cannot be adopted for new combinations.
3. **Legacy Community notification snapshots (affected acceptance gate002/006):** current reprojection bypasses non-connection notices. Parent moderation/private change/account disable can leave an old actor/path notice; no message body is added by these events, but full current-ACL privacy is unproven. Any affected privacy PASS requires safe generic reproject/suppression and stale-target tests. Existing26 direct/connection notification acceptance remains unchanged.
4. **Structured moderation/report API limitation:** storage setter is not a public route. Do not advertise response report/delete or reuse COMMENT IDs. Existing post/comment reports remain; no AI moderation. Runtime effectiveness/staffing/appeals unproven. Source capability absence is recorded, not implemented speculatively.
5. **Group pilot/query limitation:**20 retained texts, current scoped fetch-then-slice; no scale/latency guarantee.004 catch-up must query bounded rows in DB. Disabled-owner recovery, retention/deletion/backup/global-block real-private-data holds remain inherited22 gates. No production rollout authorized.
6. **Editor/locale limitation:** UTF-16 native maxlength differs from code-point validation; paired Community/Q&A English not accepted.002 tests must cover astral characters, multilingual long content and both locales before acceptance.
7. **Delivery limitations:** current context checks across pools and responses in flight are not atomic recall. Already delivered content cannot be erased by revocation; document current-check boundary and test subsequent requests.

These findings do not invalidate001 audit/freeze completion when truthfully tracked:001 ships contract/evidence only. They prevent later affected runtime/security/locale acceptance from being labeled PASS without remediation/proof. Threat-model completeness PASS means attacker/control/gate coverage reviewed, not vulnerabilities absent. No provider/global security policy/ACL/schema change is implemented here.
