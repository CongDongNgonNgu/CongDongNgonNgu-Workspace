facts that differ from the stored facts must return
`QUARANTINED` with reason
`TATOEBA_IMPORT_REJECTED_NO_REOPEN`. The resource remains rejected; no
automatic reopen or repair is allowed.

with a valid exact identity, canonical `SENTENCE` row, exact provenance,
existing `SUBMIT` then `REJECT` audit history, explicit active `ADMIN` actor,
pre-existing license rows, and meaningful incoming text drift. It executes the
same command twice against unchanged canonical facts.
